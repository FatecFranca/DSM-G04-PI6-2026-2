# Configurações desktop preservadas

As configurações Linux, macOS e Windows do projeto anterior foram mantidas aqui.
Esta pasta não faz parte dos builds web e mobile. O aplicativo utiliza o pacote
`../shared`. Para executar, use `flutter pub get` e `flutter run -d windows` (ou a
plataforma correspondente). Windows pode exigir Modo de Desenvolvedor para criar
os links dos plugins. Estes builds não foram validados nesta separação.
