# DSM-G04-PI6-2026-2

## Estrutura

- `api/`: backend Express, banco de dados e mensageria Google Pub/Sub.
- `app/web/`: frontend Flutter para navegador.
- `app/mobile/`: frontend Flutter para Android/iOS.
- `app/shared/`: telas, serviços e regras compartilhadas pelos frontends.
- `app/desktop/`: configurações desktop preservadas.
